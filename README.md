# UMA-TIC | Unidades de Microaprendizaje TIC

Plataforma educativa interactiva desarrollada para la comunidad estudiantil de la **Universidad Nacional Rosario Castellanos (UNRC)**, orientada al refuerzo de competencias clave en asignaturas de alta complejidad (Programación, Matemáticas y Ciencias Sociales).

## 🚀 Características
- **Microaprendizaje Ágil:** Cápsulas dinámicas estructuradas en teoría, recursos interactivos y ejercicios prácticos.
- **Diseño Responsivo:** Interfaz adaptada a dispositivos móviles y de escritorio mediante Tailwind CSS.
- **Enfoque Institucional:** Identidad visual alineada con la paleta de colores institucional (Vino Quemado y Dorado).

## 🛠️ Tecnologías Utilizadas
- HTML5 / CSS3
- JavaScript (Vanilla ES6+)
- Tailwind CSS (CDN)
- FontAwesome (Iconografía)
